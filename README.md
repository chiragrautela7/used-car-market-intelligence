# 🚗 Used Car Market Intelligence

An end-to-end Python data analysis project focused on understanding used car pricing, vehicle characteristics, market trends, and factors influencing resale prices.

## 📌 Project Overview

The used car market contains a large amount of information about vehicle prices, brands, fuel types, transmission types, ownership, mileage, engine specifications, and other vehicle characteristics.

This project analyzes used car data to identify pricing patterns and generate useful business insights that can support customers, dealerships, and automotive businesses in making better decisions.

## 🎯 Business Objective

The main objectives of this project are:

- Analyze used car pricing patterns
- Identify factors associated with higher vehicle prices
- Compare prices across brands and vehicle categories
- Understand the relationship between vehicle age and price
- Analyze fuel type and transmission preferences
- Identify market trends and useful business insights
- Prepare cleaned and analysis-ready data

## 🗂️ Dataset

The project uses a used car dataset containing information about vehicles and their pricing characteristics.

The dataset includes information such as:

- Vehicle name
- Brand
- Price
- Year
- Kilometers driven
- Fuel type
- Transmission
- Ownership
- Engine
- Mileage
- Seats
- Other vehicle attributes

## 🧹 Data Cleaning

The data cleaning process includes:

- Checking missing values
- Handling duplicate records
- Correcting data types
- Removing unnecessary characters
- Standardizing categorical values
- Handling inconsistent values
- Creating useful derived columns
- Validating cleaned data

The cleaned dataset is stored separately from the raw dataset.

## 📊 Exploratory Data Analysis

The analysis explores questions such as:

1. What is the overall price distribution?
2. Which brands have the highest average prices?
3. How does vehicle age affect price?
4. Does higher mileage affect resale price?
5. Which fuel types are most common?
6. Which transmission type is more common?
7. Which brands offer better value?
8. How does ownership affect vehicle pricing?
9. What characteristics are associated with expensive vehicles?
10. What are the major patterns in the used car market?

## 📈 Key Analysis Areas

### Price Analysis
Analyze average, minimum, maximum, and distribution of used car prices.

### Brand Analysis
Compare pricing and market presence across different vehicle brands.

### Vehicle Age Analysis
Study how depreciation changes as vehicles become older.

### Mileage Analysis
Analyze the relationship between kilometers driven and resale price.

### Fuel & Transmission Analysis
Understand consumer preferences and pricing differences across fuel and transmission types.
